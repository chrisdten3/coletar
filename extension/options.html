I allow Coleta to add relevant memories to my prompt when I press the website’s normal Send button or Enter, submit it, and save my prompt and the completed reply from this active conversation. Added context is visible to the AI provider and may appear in the conversation.

If recall is unavailable, my prompt is sent without added memory. Capture retries are encrypted on this device for up to 24 hours and upload only while the same site is active. Turning this mode off clears unsent captures. Enable raw capture on the Coleta server to retain turns.

What this reads

Manual mode reads your composer only. Automatic mode also observes the new reply to the prompt you just sent, while this tab and window remain active. It does not read old conversations, other tabs, account cookies, or provider credentials.

Leaving the page, stopping a response, or an unrecognized site layout can prevent reply capture. Stored assistant replies are evidence, not user facts; only user turns enter memory extraction. This integration is best effort and does not cover native or mobile apps.
