coletar — your context broker

One memory. Every AI you use.

coletar sits between every AI tool you use and brokers your context to them — one typed graph of your facts, preferences, decisions and project state, that you own, instead of each assistant keeping its own separate, disconnected memory of you.

Live Sync is Plaid for memory — every connected tool reads the same live graph. True Migration is closer to actually switching banks — it moves your context into a new tool's own native format, so you can leave and it still works.

About

What coletar actually is

Right now, every AI assistant keeps its own separate memory of you. Tell ChatGPT your favorite programming language, and Claude has no idea. Run a model locally, and it starts from nothing every time. coletar is your context broker — it sits underneath every AI tool you use, holding one single memory graph and handing each tool exactly the context it needs, so what you tell one, the others can know too, if you choose to let them.

It has no chat interface of its own, and isn't meant to. You keep using claude.ai, chatgpt.com, or your local model exactly as you do today — coletar is the shared memory those tools read from and write to, not another tool you have to visit.

Two ways it moves your context

Live Sync keeps one graph authoritative, and every connected tool queries it in real time. Nothing is ever "moved" — you're always a client of your own memory, the way Plaid lets an app read your bank account without owning it.

True Migration is a one-time, point-in-time compile of your graph into a destination tool's own native format — its actual project files, its actual system prompt — so that afterwards you can disconnect coletar entirely and the destination still works on its own. Closer to actually switching banks than linking one.

How it's built, for the technically curious

Every fact, decision, and project detail is one typed object in a single graph — with provenance (who said it, and how confident the system is), full version history, and nothing ever hard-deleted. It runs with zero infrastructure for a single user, or on Postgres with real vector search for anything bigger, and every AI tool reaches it the same way: as a hosted MCP server, the same protocol Claude and ChatGPT already speak to external tools.

Selective Context

Not everything needs to go everywhere

Sometimes it's compliance — customer details that can never reach a certain model. Sometimes it's simpler than that — you don't want ChatGPT fixating on some irrelevant detail from a Claude conversation just because it happened to be sitting in the same graph. Either way, coletar lets you control exactly which part of your context moves between models, and which stays put. Fully secure, SOC2 Compliant (WIP), GDPR Compliant (WIP).

In plain terms: Live Sync's default is that everything you save is visible everywhere. Selective Context lets you pick exceptions — a fact stays exactly where you put it.
