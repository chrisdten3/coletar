# Icon sources

Interface controls use selected Lucide SVGs from `lucide-static@1.44.0` (ISC), the
icon family used by shadcn/ui. They are served in `icons.svg` as a local SVG sprite.
No React conversion or icon runtime is needed for this vanilla JavaScript app.

Claude, Ollama, and Markdown marks come from `simple-icons@16.30.0` (CC0).
ChatGPT/OpenAI and Claude Code marks come from `@lobehub/icons-static-svg@1.95.0`
(MIT). Copyright and license notices are in `licenses/`.
Brand marks identify the corresponding services; their trademarks remain the
property of their owners. OpenAI's mark is rendered in monochrome.

The coletar identity and the context-atlas ribbon artwork are original artwork.
Generic local models use Lucide's CPU; Ollama uses its brand mark when named.

Sources:
- https://lucide.dev/guide/static
- https://github.com/lucide-icons/lucide
- https://github.com/simple-icons/simple-icons
- https://github.com/lobehub/lobe-icons
- https://openai.com/brand/
